## 🔧 Installation

### Schritt 1: Herunterladen und Entpacken

- Laden Sie `Yuzu-Nintendo-Switch-Emulator.zip` herunter (~50 MB)
- Entpacken Sie mit WinRAR oder 7-Zip. **Kein Passwort.**

### Schritt 2: Keys hinzufügen

- Öffnen Sie den Ordner `/keys`
- Kopieren Sie `prod.keys` hinein
- Benennen Sie die Datei nicht um

### Schritt 3: Firmware installieren

- Öffnen Sie Yuzu
- Gehen Sie zu **File → Install Firmware**
- Wählen Sie die Firmware-ZIP-Datei
- Warten Sie, bis die Installation abgeschlossen ist

### Schritt 4: Grafik konfigurieren

- Öffnen Sie **Emulation → Configure → Graphics**
- Wählen Sie **Vulkan**
- Stellen Sie Auflösung und FPS-Limit ein

### Schritt 5: Spiel und Controller hinzufügen

- **File → Load File** → NSP oder XCI auswählen
- Controller anschließen
- Tasten konfigurieren über **Emulation → Configure → Controls**
